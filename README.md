# Financial Stock-chart-tool

## Purpose

This project simulates a set of entities moving in a 2D space. Each entity has a position and oscillation frequencies that determine its movement pattern. The entities move along sine wave patterns with different frequencies along each dimension, creating interesting visual patterns when visualized.

This project is an improved version of the `00-simple-entities` starter project(mai.cpp), restructured to use proper C++ coding practices including:
- Separate header and implementation files
- Configuration management using JSON files
- Proper use of classes
- Random number generation
- Standards-compliant C++ code
